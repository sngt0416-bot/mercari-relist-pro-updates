# Mercari Relist Pro — 更新情報

配布した Mercari Relist Pro が「最新版はどれか」を確認するための置き場です。
**アプリのソースコードはここにはありません**（別の非公開リポジトリにあります）。

## latest.json

| 項目 | 意味 |
|---|---|
| `version` | 最新版のバージョン番号 |
| `downloadUrl` | ダウンロード先（Google Drive の共有リンクなど） |
| `notes` | 変更点。アプリの更新のお知らせに表示されます |

アプリはこのファイルを読み、自分のバージョンより新しければ利用者に知らせます。

## リリースのしかた

1. 新しい版をビルドする
2. できたファイルをアップロードし、共有リンクを取得する
3. `latest.json` の `version` / `downloadUrl` / `notes` を書き換えて push する

これだけで、配布済みのアプリすべてに更新が伝わります。
